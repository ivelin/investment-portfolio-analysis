# Extraction Template: 1099-R / Tax Documents

**File type**: 1099-R PDFs or structured exports

**Primary target table**: `gt_1099r_distributions`

## SOTA VQA Prompt

```
Extract all distribution information from this 1099-R document.

Focus on:
- Recipient information
- Payer information
- Gross distribution
- Taxable amount
- Federal income tax withheld
- Distribution codes

Return only valid JSON:

{
  "source_file": "FILENAME.pdf",
  "tax_year": 2022,
  "recipient": { ... },
  "distributions": [
    {
      "gross_distribution": 0,
      "taxable_amount": 0,
      "federal_tax_withheld": 0,
      "distribution_code": "..."
    }
  ]
}
```

## Preferred Ingestion

Use `ingest_1099r_distribution()` from `portfolio_analysis.ingest`.
